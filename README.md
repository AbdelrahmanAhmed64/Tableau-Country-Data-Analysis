# Country Data Analysis Using Tableau

## Project Overview

This project focuses on analyzing country data using Tableau

The dataset includes different economic, demographic and public health indicators for several countries

The goal was to explore the data, compare countries and find useful patterns and insights through interactive visualizations

## What I Worked On

- Explored and analyzed the dataset
- Created different types of visualizations
- Built geographical maps to compare countries
- Analyzed trends across different indicators
- Created calculated fields and parameters
- Added interactive filters and dashboard actions
- Connected visualizations across dashboards
- Built a Tableau Story to present the main findings

## Dashboards

The project includes interactive dashboards with different visualizations to explore country data and compare indicators

It also includes geographical analysis and trend analysis to make comparisons easier

## Interactive Features

- Filters
- Parameters
- Calculated Fields
- Dashboard Actions
- Dynamic Navigation
- Interactive Dashboards

## Tableau Story

Created a Tableau Story to organize the analysis and present the main findings in a clear way
